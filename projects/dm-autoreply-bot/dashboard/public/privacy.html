개인정보처리방침

DM봇 (인스타그램 DM 자동답변) · 시행일 2026년 10월 19일

DM봇은 운영자(홍길동)의 인스타그램 프로페셔널 계정으로 받은 Direct 메시지에 운영자를 대신해 답장하는 개인용 서비스입니다. 이 방침은 해당 계정에 메시지를 보낸 분의 정보를 어떻게 처리하는지 설명합니다.

1. 처리하는 정보

항목내용
인스타그램 식별 정보Instagram이 제공하는 사용자 ID(IGSID), 사용자 이름(아이디), 표시 이름
메시지운영자 계정과 주고받은 Direct 메시지의 텍스트와 보낸 시각. 사진·동영상·게시물 공유 등 첨부는 저장하지 않습니다
약속 기록약속 요청 메시지와 운영자가 정한 날짜

위 정보는 Instagram Messaging API(Meta)를 통해서만 받으며, 그 밖의 경로로 수집하지 않습니다.

2. 이용 목적

  • 받은 메시지에 대한 답장 작성·발송
  • 운영자가 대화 내용을 확인할 수 있도록 대화 요약 작성
  • 약속 요청 관리

광고, 마케팅, 프로필 분석, 제3자 판매 목적으로 이용하지 않습니다.

3. 처리 위탁 (서비스 제공에 쓰는 외부 업체)

업체역할
Meta Platforms (Instagram)메시지 수신·발송
Supabase데이터 저장 (메시지 원문은 AES-256-GCM 으로 암호화해 저장)
Anthropic (Claude API)답장·요약 문장 생성. 최근 대화 일부가 생성 요청에 포함됩니다
Cloudflare서비스 서버 운영

4. 보관 기간

정보보관 기간
메시지 원문90일 후 자동 삭제
발송 기록180일 후 자동 삭제
처리 대기 기록30~90일 후 자동 삭제
완료·취소된 약속 기록180일 후 자동 삭제

5. 안전성 확보 조치

  • 메시지 원문 암호화 저장, 관리 화면은 운영자 1인만 로그인 가능
  • Instagram 웹훅은 서명 검증 후에만 처리, 모든 통신은 HTTPS

6. 정보 삭제 요청과 권리

본인의 정보 열람·삭제를 원하시면 운영자 인스타그램 계정으로 Direct 메시지를 보내 "데이터 삭제 요청"이라고 알려 주세요. 확인 후 30일 이내에 해당 사용자 ID 와 연결된 메시지·요약·약속 기록을 모두 삭제하고 결과를 알려 드립니다. Instagram 설정에서 이 서비스의 연결을 해제할 수도 있습니다.

7. 문의

운영자: 홍길동 · 문의: 운영자 인스타그램 계정 Direct 메시지

Privacy Policy (English summary)

DM봇 · Effective October 19, 2026

DM봇 is a personal service that replies on behalf of its operator (Gildong Hong) to Direct messages received by the operator's Instagram professional account.

  • Data processed: Instagram-scoped user ID, username and display name; text and timestamps of Direct messages exchanged with the operator's account; appointment requests. Attachments are not stored. Data is received only through the Instagram Messaging API.
  • Purpose: composing and sending replies, summarizing conversations for the operator, managing appointment requests. No advertising, profiling or sale to third parties.
  • Processors: Meta (messaging), Supabase (storage; message text encrypted with AES-256-GCM), Anthropic Claude API (reply and summary generation), Cloudflare (hosting).
  • Retention: message text 90 days, send logs 180 days, then deleted automatically.
  • Data deletion: send a Direct message saying "data deletion request" to the operator's Instagram account. All messages, summaries and appointment records linked to your user ID will be deleted within 30 days and you will be notified.
  • Contact: Direct message to the operator's Instagram account.
