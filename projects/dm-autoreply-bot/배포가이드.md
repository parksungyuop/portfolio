# 배포 가이드 — 인스타 DM 자동답변 봇 (Cloudflare 버전)

다른 프로젝트(`preview.example.com`)와 같은 방식으로 **Cloudflare 한 곳**에서 돌아갑니다. cPanel은 필요 없습니다.

```
https://bot.example.com/            대시보드 (오너 로그인)
https://bot.example.com/ig/webhook  Instagram 웹훅
https://bot.example.com/ig/api      대시보드 API
크론: 매 분 답장 처리 · 매일 04:00(KST) 토큰 갱신·요약·정리
```

| 구성 | 위치 |
|---|---|
| Worker 코드 | `worker/` (`src/`, `wrangler.toml`) |
| 대시보드 | `dashboard/` → 빌드 결과물을 Worker가 같이 서비스 |
| DB·로그인 | Supabase **IG BOT project** (`YOUR_PROJECT_REF`, 서울) |
| 비밀값 | `worker/secrets.local.env` (이 PC에만) → `npm run secrets`로 Cloudflare에 등록 |

## A. Worker 배포

```bash
cd "C:\인스타그램 대화내용\worker"
npm run deploy
```
- 대시보드를 빌드한 뒤 Worker와 함께 올리고, `bot.example.com`를 자동으로 연결합니다 (DNS 자동 추가, 기존 `example.com`는 안 건드림).
- 비밀값을 등록하기 전까지 크론은 매 분 오류만 남기고 아무것도 보내지 않습니다 (DB 전체 스위치도 OFF 상태).

**확인**: `https://bot.example.com/` → 로그인 화면. 몇 분 걸릴 수 있음.

## B. Meta 앱 설정 (Instagram API with Instagram Login)

1. **휴대폰 인스타**: 설정 → 메시지 및 스토리 답장 → 메시지 컨트롤 → 연결된 도구 → **메시지 접근 허용** 켜기
2. developers.facebook.com → 앱 만들기 → 사용 사례 **"Instagram에서 메시지 및 콘텐츠 관리"**
3. 권한: `instagram_business_basic`, `instagram_business_manage_messages`
4. **API setup with Instagram login** → Generate token → 내 인스타 계정 연결 → 토큰 복사
5. `worker/secrets.local.env`를 메모장으로 열어 채우기:
   - `IG_ACCESS_TOKEN=` 복사한 토큰
   - `IG_TOKEN_EXPIRES_AT=` 아래 명령 출력값
     ```bash
     python -c "import time;print(int(time.time())+60*86400)"
     ```
   - `IG_APP_SECRET=` 앱 설정 → 기본 설정 → **앱 시크릿**
6. **웹훅 등록**: Callback URL `https://bot.example.com/ig/webhook`, Verify token은 `secrets.local.env`의 `IG_VERIFY_TOKEN` 값
   - "Verify and save"는 **C 단계(비밀값 등록) 후에** 눌러야 성공합니다
   - 구독 필드: **messages**, **message_echoes**
7. 부계정을 앱 **테스터**로 추가. 일반 사용자 DM까지 받으려면 개인정보처리방침 URL 입력 → Live 전환 → 앱 검수

## C. 비밀값 등록

```bash
cd "C:\인스타그램 대화내용\worker"
npm run secrets
```
- `secrets.local.env`의 값을 형식 검사 후 Cloudflare에 등록합니다. 값은 화면에 출력되지 않아요.
- 형식만 먼저 확인: `node upload-secrets.mjs --dry-run`
- 값을 바꾸면 다시 실행하면 됩니다 (재배포 불필요).

**확인**: 브라우저에서
`https://bot.example.com/ig/webhook?hub.mode=subscribe&hub.verify_token=<IG_VERIFY_TOKEN>&hub.challenge=123` → `123`이 보이면 정상. 그다음 Meta에서 "Verify and save".

## D. 최종 점검 (부계정)

대시보드 상대 목록은 DM을 한 번 받아야 생기고, 새 상대는 **자동발송 꺼짐**으로 등록됩니다.

1. 전체 OFF 상태에서 부계정 → DM → 목록에 등장, 답장 없음
2. 부계정 토글 켬 → 전체 켜기 → DM → 20초~1분 뒤 내 말투로 답장 (ㅋㅋ 없음)
3. 인스타 앱에서 내가 직접 답장 → 부계정 DM → 답장 없음, "일시정지" 표시
4. 내가 "사실 이거 홍길동 봇이야" 전송 → 자기소개 발송
5. 부계정이 게시물 공유 → 답장 없음
6. 부계정 "이번 주말에 볼래?" → "시간 확인해보고 알려줄게"류 답장 + 약속 탭에 등장 → 날짜 골라 "날짜 보내기"
7. "돈 언제 줄 거야" → 답장 없이 "주의 필요"
8. 전체 끄기 → DM → 답장 없음

## 운영

| 하고 싶은 것 | 방법 |
|---|---|
| 실시간 로그 보기 | `cd worker && npx wrangler tail` |
| 코드·대시보드 수정 후 반영 | `npm test` 통과 확인 → `npm run deploy` |
| 답장 모델 바꾸기 | `wrangler.toml`의 `CLAUDE_MODEL_REPLY` → `npm run deploy` |
| 비밀값 바꾸기 | `secrets.local.env` 수정 → `npm run secrets` |
| 대시보드 로컬 확인 | `cd dashboard && npx vite build --mode devlocal` → `cd worker && node test/dev.mjs` → http://127.0.0.1:8788/ (확인 후 `npx vite build`로 다시 빌드) |

**무료 플랜 한도**: 실행 1회당 외부 호출 50회 → 매 분 상대 2명 정도씩 처리 (`MAX_SUBREQUESTS=45`). 밀리면 Workers Paid($5/월)로 올리고 `MAX_SUBREQUESTS`를 1000으로.

## 문제 해결

| 증상 | 원인·조치 |
|---|---|
| Meta "Verify and save" 실패 | C 단계 비밀값 등록 여부, 토큰 오타. 위 확인 URL로 `123`이 나오는지 |
| DM을 보내도 대시보드에 상대가 안 생김 | ① 인스타 "메시지 접근 허용" ② 웹훅 필드 구독 ③ 테스터 여부 ④ `wrangler tail`에 403 → `IG_APP_SECRET` 확인. 그래도 안 되면 Cloudflare → 보안 → **Bots(봇 차단 모드)**가 Meta 요청을 막는지 확인 |
| 답장이 안 나감 | 전체 스위치·상대 토글·일시정지 확인. "주의 필요" 탭의 사유 확인 |
| 대시보드 "주의 필요/약속" 탭 오류 | `SUPABASE_SERVICE_KEY` 등록 여부 (`npm run secrets`) |
| 토큰 만료 경고·"인스타 연결이 끊김" 배너 | 매일 04:00 자동 갱신·연결 확인. 끊겼으면 **PC에서** B-4~5 다시 → `npm run secrets` (폰에서는 등록 불가). 새로 등록한 토큰은 다음 답장부터 바로 쓰임 |

## 정리할 것 (Cloudflare로 옮기며 안 쓰게 된 것)

- `server/` (PHP 버전), `deploy/` (cPanel 업로드용 zip·config.php) — 배포가 끝나면 지워도 됩니다. `deploy/dmbot/config.php`의 암호화 키는 이미 `secrets.local.env`로 옮겨 두었어요.
- `tools/tone.env`, 인스타 내보내기 폴더·zip — 말투를 다시 학습할 계획이 없으면 삭제
