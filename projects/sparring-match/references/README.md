## 사용 원칙 (중요)

- 이 이미지들은 **내부 무드 보드/디자인 참고 전용**입니다. 20세기 폭스(현 디즈니) 소유의 저작물이므로 앱·웹사이트·마케팅 어디에도 게시·재배포하지 않습니다.
- 설계서 §5.3에 명시된 대로, 영화의 `FIGHT CLUB` 로고·타이포그래피·레이아웃을 복제하거나 유사한 워드마크를 상표로 쓰지 않습니다. **분위기(색·광원·긴장감)만 차용**합니다.
- 서비스명 `SparringMatch`도 출시 전 상표 선행조사가 필요합니다(설계서 §2.2 참고).
- 영화의 "싸움 모임" 콘셉트 자체는 무규칙·비동의 폭력이므로 서비스 메시지와 정반대입니다. 마케팅에서 영화를 직접 인용·연상시키는 카피는 법무 검토 전까지 금지합니다.
