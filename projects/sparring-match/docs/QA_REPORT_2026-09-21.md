## 2. 개선할 점 📝

1. **인증 부재**: 모든 API가 `userId`를 본문/쿼리로 신뢰 → 타인 대화 열람·사칭 가능(`/api/conversations?userId=sora`). mock 한계로 README에 명시돼 있으나, 외부 공개 전 세션 토큰은 필수.
2. `favicon.ico` 요청이 403(허용 확장자 아님) → 콘솔 오류 1건. SVG 파비콘 추가 권장.
3. `render()`가 매번 `#app` 전체를 교체 → 포커스·스크롤 유실. 화면 단위 부분 갱신 또는 경량 뷰 라이브러리 검토.
4. 인라인 `style="…"` 다수(홈 compact-row 등) → 클래스로 이전.
5. 이벤트 상세의 "관심 표시", 글쓰기, 프로필 수정, 상세 조건은 안내 모달만 뜸 → 실제 동작 또는 "준비 중" 표기 통일.
6. 프로필 완성도 `82%` 하드코딩.
7. `data/match-chat.json` 동시 쓰기는 직렬화돼 있으나 프로세스 비정상 종료 시 파일 손상 가능 → 임시 파일 쓰기 후 rename.
8. 요청 본문 `purpose/intensity/venueType`은 서버에서 허용값 검증 없음(길이만 제한).
9. 설계서 문서 불일치: §5.4 아이콘 색이 v1 토큰(`#0B0B0D`,`#E63946`) 잔재, 없는 토큰 `--text-secondary`·`--status-safe` 참조, §2.1(6종목) vs §1.4·시장분석(태권도 제외) 모순, §3.1 페르소나의 "안전 체크인·후기"가 §4.1 MVP 표에 없음.
