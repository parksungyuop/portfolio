# 데스크톱 펫 (Codex 펫 패키지 뷰어)

Codex에서 쓰던 펫 패키지(`pet.json` + 스프라이트시트)를 그대로 읽어서
윈도우 **바탕화면 위**에 띄우는 독립 실행 앱입니다.
Claude Code에는 펫 기능이 없기 때문에, 같은 에셋을 재사용하는 별도 프로그램으로 만들었습니다.

## 실행

```
펫 실행.vbs
```

더블클릭하면 콘솔 창 없이 펫이 뜹니다. 종료는 트레이 아이콘 우클릭 → **종료**.

| 파일 | 용도 |
| --- | --- |
| `펫 실행.vbs` | 평소 실행용 (콘솔 없음) |
| `디버그 실행.bat` | 오류 메시지를 콘솔로 보고 싶을 때 |
| `펫 종료.bat` | 트레이가 사라졌을 때 강제 종료 |

## 조작

| 동작 | 결과 |
| --- | --- |
| 마우스를 펫 근처로 | 커서 방향을 16방향으로 쳐다봅니다 |
| 드래그 | 집어서 옮깁니다. 던지면 중력을 받아 떨어지고 바닥에서 튕깁니다 |
| **더블클릭** | **Claude 데스크톱 앱을 실행합니다** (이미 켜져 있으면 그 창이 앞으로 나옵니다) |
| 우클릭 | 메뉴 (Claude 열기, 동작 강제 실행, 펫 교체, 크기, 옵션) |
| 트레이 아이콘 우클릭 | 같은 메뉴 |

가만히 두면 걷기 · 인사 · 점프 · 대기 · 작업중 · 시무룩 · 폭발을 가중치 랜덤으로 섞어 연기합니다.
(점화 → 폭발 → 재생성 연출은 우클릭 → **동작 시키기 → 점화 · 폭발 · 재생성** 에 있습니다.)

## Claude 연동

### 더블클릭으로 실행

처음 실행할 때 시작 메뉴 앱 목록에서 Claude를 찾아 `config.json`에 캐시합니다.
찾는 순서는 시작 메뉴 AppID → 시작 메뉴 바로가기 → `claude://` 프로토콜 핸들러입니다.
AppID는 앱을 업데이트해도 바뀌지 않아서 버전이 박힌 설치 경로보다 안전합니다.

못 찾거나 다른 걸 띄우고 싶으면 우클릭 → **Claude 실행 설정 → 실행 대상 직접 지정...** 에서
아무 `.exe` / `.lnk` / `.bat`을 골라도 됩니다.

### 작업 중이면 같이 일하기

Claude Code는 대화가 진행되는 동안 `~/.claude/projects/<프로젝트>/<세션>.jsonl`에
내용을 계속 덧붙입니다. 펫은 2초마다 이 파일들의 최근 수정 시각을 확인해서,
**25초 안에 갱신됐으면 "작업 중"**으로 보고 안경을 쓰고 노트북 앞에 앉습니다.
Claude가 멈추면 다시 원래대로 돌아다닙니다.

- 설정이나 훅을 따로 걸 필요가 없습니다. 켜져 있는 모든 Claude Code 세션에 반응합니다.
- 끄려면 우클릭 → **Claude 실행 설정 → 작업 중이면 노트북 자세로 앉기** 체크 해제
- 반응 시간을 바꾸려면 `config.json`의 `claude_activity_window_sec` 값을 조정하세요
- 감지 대상은 **Claude Code 세션**입니다. 데스크톱 앱에서 하는 일반 채팅은 이 파일을 쓰지 않습니다

안경과 노트북은 원본 스프라이트시트에 없어서 `working_pose.py`가 실행 시점에 합성합니다.
시선 행의 180°(정면 아래) 프레임을 바탕으로 삼아 고개를 숙이게 하고,
얼굴에서 어두운 눈 덩어리를 찾아 그 위에 안경을 씌운 뒤 앞에 노트북을 그립니다.
눈 위치를 좌표로 박아두지 않아서 다른 펫에도 그대로 동작합니다.

## 말풍선

펫 머리 위에 말풍선이 떠서 한마디씩 합니다. 대사는 **상황별로 나뉘어 있고 직접 고칠 수 있습니다.**

우클릭 → **말풍선 → 대사 설정...** 에서 왼쪽 목록으로 상황을 고르고,
오른쪽에 **한 줄에 대사 하나씩** 적으면 됩니다. 빈 줄은 무시합니다.

| 상황 | 언제 나오는지 |
| --- | --- |
| 평소 | 가만히 있을 때 정해진 간격마다 하나씩 |
| 작업 시작 | Claude가 일을 시작한 순간 한 번 |
| 작업 중 | 일하는 동안 정해진 간격마다 하나씩 |
| 작업 끝 | Claude가 멈춘 순간 한 번 |
| 집어 들었을 때 | 마우스로 잡아 올릴 때 |
| Claude 열기 | 더블클릭으로 Claude를 띄울 때 |

같은 상황에서 방금 한 대사는 연달아 다시 나오지 않습니다.
대사를 전부 지우면 그 상황에서는 아무 말도 하지 않습니다.

- **미리보기** — 커서가 놓인 줄을 지금 화면에 띄워 봅니다
- **이 상황 기본값** — 고른 상황의 대사만 처음 상태로 되돌립니다
- **말풍선이 떠 있는 시간** 1 ~ 30초
- **평소 대사가 나오는 간격** 최소 ~ 최대 (그 사이에서 무작위로 뽑습니다)
- **글자 크기** 7 ~ 24 pt

말풍선을 잠깐 끄려면 우클릭 → **말풍선 → 말풍선 띄우기** 체크를 해제하세요.
같은 메뉴의 **지금 말하기** 로 상황별 대사를 바로 확인할 수도 있습니다.

말풍선 창은 클릭이 그대로 통과하도록 만들어져 있어서, 펫을 드래그하거나
말풍선 뒤에 있는 창을 누르는 데 걸리적거리지 않습니다.
설정값과 대사는 `config.json`의 `speech` 항목에 저장됩니다.

## 설정

우클릭 메뉴에서 바꾼 값은 `config.json`에 저장되어 다음 실행에도 유지됩니다.

- **크기** 30 / 40 / 50 / 70 / 100 %
- **마우스 따라 보기** 끄기/켜기
- **항상 위에 표시** 끄기/켜기
- **윈도우 시작 시 자동 실행** — `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`에
  항목을 추가/삭제합니다. 관리자 권한은 필요 없고, 같은 메뉴에서 다시 끄면 깨끗이 지워집니다.

## 펫 추가하기

`%USERPROFILE%\.codex\pets\<펫이름>\` 아래에 `pet.json`과 스프라이트시트를 두면
앱이 시작할 때 자동으로 찾아냅니다. 펫이 2개 이상이면 우클릭 메뉴에 **펫 바꾸기**가 생깁니다.
(`CODEX_HOME` 환경변수를 설정했다면 그 경로를 따릅니다.)

### 그림에서 펫 만들기 — `make_petpack.py`

아틀라스를 손으로 맞출 필요 없이, 포즈별 그림 폴더를 넣으면 규격에 맞춰 뽑아 줍니다.

```
python make_petpack.py 작업폴더 --init
```

먼저 이걸로 빈 하위 폴더 뼈대를 만들고, 폴더마다 그림을 순서대로 넣습니다.

```
작업폴더/
  idle/            01.png 02.png ...      (필수)
  running-right/   01.png ...
  running-left/    ...                    (--mirror 로 자동 생성 가능)
  waving/  jumping/  failed/  waiting/  running/  review/
  look/            00.png ... 15.png      (선택)
```

한 폴더에 `idle-01.png`, `waving-02.png` 처럼 이름 앞에 붙여 넣어도 인식합니다.
파일 순서는 숫자를 숫자로 보고 정렬하므로 `2.png`가 `10.png` 앞에 옵니다.

```
python make_petpack.py 작업폴더 --id my-pet --name "내 펫" --mirror
```

`~/.codex/pets/my-pet/`에 `spritesheet.webp` + `pet.json` + `preview.png`를 만들고,
앱이 쓰는 로더로 다시 읽어 정말 열리는지까지 확인한 뒤 결과를 알려 줍니다.

| 옵션 | 하는 일 |
| --- | --- |
| `--mirror` | 걷기 좌우 중 한쪽만 있으면 뒤집어서 나머지를 만듭니다 |
| `--remove-bg` | 네 모서리에서 번져 나가며 단색 배경을 지웁니다 |
| `--bg-tolerance N` | 배경으로 볼 색 차이 (기본 30) |
| `--align union\|each` | union=프레임 간 움직임 유지, each=한 장씩 바닥에 맞춤 (기본 자동) |
| `--pad N` | 셀 안쪽 여백 (기본 6px) |
| `--force` | 출력 폴더를 덮어씁니다 |
| `--dry-run` | 파일을 쓰지 않고 어떤 행이 채워지는지만 보여 줍니다 |

**모든 프레임에 같은 축소 배율을 씁니다.** 프레임마다 따로 맞추면 걸을 때 캐릭터가
커졌다 작아졌다 하며 떨립니다. 원본 캔버스 크기가 전부 같으면 `union` 정렬을 골라
프레임 사이의 상대적인 움직임(점프로 떠오르는 높이 같은 것)도 그대로 살립니다.

**빈 행은 그냥 비워 둡니다.** 로더가 "사용 안 함"으로 읽어서 그 동작만 건너뜁니다.
`idle`만 반드시 있어야 합니다. 시선(`look`)이 없으면 커서를 따라볼 때 `idle`로 대체됩니다.
시선 그림 파일 이름이 숫자면 그 숫자를 방향 번호로 써서, 중간이 비어도 방향이 밀리지 않습니다.

`preview.png`는 행 이름을 붙인 축소판입니다. 넣기 전에 눈으로 한 번 훑어보세요.

## 지원하는 아틀라스 규격

Codex v2 계약(`~/.codex/skills/hatch-pet/references/codex-pet-contract.md`)과 동일합니다.

- `spriteVersionNumber: 2`, 1536 × 2288 RGBA, 8열 × 11행, 셀 192 × 208
- 행 0–8 : idle, running-right, running-left, waving, jumping, failed, waiting, running, review
- 행 9–10 : 시계방향 16방향 시선 (0° = 위/12시, 22.5° 간격). 정면은 데드존이라 idle로 폴백
- 프레임별 지속시간은 `petpack.ANIMATIONS`에 스펙 값 그대로 들어 있습니다
- 표준 행에서 완전히 투명한 셀은 "사용 안 함"으로 보고 건너뜁니다

v1(11행이 아닌) 펫은 명확한 오류 메시지와 함께 건너뜁니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `petpack.py` | 펫 패키지 탐색 · 매니페스트 검증 · 아틀라스 슬라이싱 |
| `main.py` | 투명 창, 행동 상태머신, 물리, 시선 추적, 메뉴/트레이 |
| `launcher.py` | Claude 실행 방법 탐색 및 실행 |
| `activity.py` | Claude Code 세션 파일을 폴링해 작업 중인지 판단 |
| `working_pose.py` | 안경 + 노트북 프레임 합성 (눈 위치 자동 탐지) |
| `speech.py` | 말풍선 창 · 상황별 대사 선택 · 등장 간격 |
| `speech_dialog.py` | 대사 설정 창 |
| `make_petpack.py` | 포즈 이미지 폴더 → 스프라이트시트 + `pet.json` 변환 |

## 요구 사항

- Windows, Python 3.12
- `PyQt6`, `pillow` (설치 완료됨)

반투명 픽셀이 6%가량(그림자·외곽선) 있어서, 픽셀 단위 알파를 지원하는 PyQt6로 그립니다.
tkinter의 단색 투명키 방식으로는 캐릭터 주변에 테두리가 남습니다.
