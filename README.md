# 포트폴리오

사이트(`index.html`)와 개인 프로젝트 코드를 한 저장소에 묶었다. `index.html`을 브라우저로 열면 포트폴리오, `projects/`에 각 프로젝트 코드.

| 폴더 | 내용 | 스택 |
|---|---|---|
| [projects/sparring-match](projects/sparring-match) | 스파링 파트너 매칭 웹 베타 | Vanilla JS · Node.js 내장 서버 |
| [projects/dm-autoreply-bot](projects/dm-autoreply-bot) | 인스타그램 DM 자동답변 봇 | Cloudflare Worker · PHP 8 · Supabase · Claude API |
| [projects/dealer-matching](projects/dealer-matching) | 홀덤펍 딜러 매칭 MVP | Next.js · TypeScript · Prisma |
| [projects/voice-assistant](projects/voice-assistant) | 음성 데스크톱 AI 비서 | TypeScript · Electron · Claude Agent SDK |
| [projects/desktop-pet](projects/desktop-pet) | 바탕화면 펫 | Python · PyQt6 |
| [projects/racing-data-collector](projects/racing-data-collector) | 경마 데이터 수집기 | Python · SQLite |

외주 작업은 고객사 코드라 포함하지 않고 사이트에 화면만 실었다. 화면의 로고와 이름은 가렸다.
비밀값(.env, API 키, DB 파일), 운영 식별자, 개인 대화 데이터는 저장소에 없다.
