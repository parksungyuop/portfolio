  • 사업기획서와 제품 개발 계획서까지 직접 작성했습니다

DM 자동답변 봇

공식 Instagram API로 DM을 받고, 계정 주인의 말투를 학습한 Claude가 대신 답장합니다. 공유 호스팅에서도 돌아가도록 PHP 의존성을 0개로 맞췄습니다.

Instagram ─webhook─▶ webhook.php ─▶ Supabase queue
                                         ▲
cron(1분) ─▶ worker ─ claim_jobs() ─▶ Claude ─▶ ig_send()
대시보드 ─JWT + RLS─▶ Supabase
  • 같은 DM이 두 번 나가지 않도록 4중으로 막았습니다: flock, DB 임대, UNIQUE 제약, 발송 중 상태 선기록
  • 상대마다 말투 프로필(존댓말 비율, 평균 길이)을 따로 두고, 내가 직접 대화 중이면 봇이 알아서 일시정지합니다
  • 약속 잡기와 알림, 대화 학습 메모리, Claude 사용량 집계까지 대시보드에서 관리합니다
  • FOR UPDATE SKIP LOCKED 대기열로 크론이 겹쳐 실행돼도 문제가 없습니다
  • 메시지 원문은 AES-256-GCM으로 암호화하고, 발송을 끄는 스위치는 코드 한 곳에서만 확인합니다

데이트 코스 추천 앱

회원가입 때 받은 취향 체크리스트와 챗봇의 질문을 조합해 데이트 코스를 짜 주는 앱입니다. 대표님 요청을 받아 v2부터 v10까지 다듬었고, 마지막 디자인판(v10d)은 그린 테마로 화면을 다시 그렸습니다.

  • 코스 결과는 지도 위에 동선과 도보 시간을 표시하고, 반영한 조건과 반영하지 못한 조건을 함께 보여줍니다
  • 오늘의 카드, 에디터 추천, 커뮤니티, 레드코인 같은 수익 모델까지 화면으로 기획했습니다
  • 버전마다 320px과 1280px 화면, 다크 모드를 캡처해 검증 기록을 남겼습니다

코스 엔진 모듈

코스는 규칙 코드가 짜고, AI는 사람이 쓴 문장을 이해하는 데만 씁니다. 칩으로만 답한 요청은 AI를 한 번도 부르지 않습니다.

  1. 취향 읽기꼭 지킬 조건과 가중치로 나눔
  2. 코스 틀시간대·일정으로 자리 순서
  3. 거르기19+, 식단, 술 조건
  4. 중심 가게점수 상위 식당 먼저
  5. 자리 채우기700m 안 후보 조합
  6. 일정 맞추기넘치면 뒤 자리 줄임
  7. 3코스 고르기서로 겹치지 않게
  8. 결과 정리동선, 대안, 경고
engine/engine.py
위 8단계를 실행하는 코스 엔진(Python). 코스를 최대 3개 만들고, 자리마다 대안 가게를 함께 둡니다
engine/reddata.py
가게 자료(SQLite). 강남구 실제 장소 약 1만 1천 곳과 가게 특징 태그, 영업시간
engine/ai.py
Claude 연동. 자유 문장을 조건표로 바꾸고, 코스 설명 글을 씁니다. 키가 없으면 규칙 해석으로 대신해 결과가 같습니다
engine/flow/
점수 계산 과정을 시나리오 12개로 보여 주는 설명 페이지(함께 실은 캡처)
data/
장소 수집 스크립트와 전국 법정동 4단계 지역 자료
tests/, engine/test_*.py
